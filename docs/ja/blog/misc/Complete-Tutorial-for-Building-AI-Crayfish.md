# 2ドルでAIザリガニを構築する完全チュートリアル（OpenClaw + Zeabur）

### 一、開始前の説明

この方法は次のような人に向いています：

- コードの基礎がない初心者
- AIザリガニを試してみたいだけの人
- 最初からあまりコストをかけたくない人

<!-- more -->

核心となる原則は一言だけ：

**まずは最小コストで一連の流れを動かす。**

実際に使うようになってから、サーバーのアップグレードを検討しましょう。

### 二、用意するものは2つ

1. Zeabur サーバー
2. ChatGPT の月額モデル

では始めます。

### 三、ステップ1：2ドルのサーバーを購入

[zeabur](https://zeabur.com) の公式サイトに入ってアカウント登録します。

最小構成のプランを選べばOKです。

クレジットカード、Alipay、WeChat Pay に対応しています。

決済時に「sakura」を入力すると、10%割引になります～

#### サーバー購入のイメージ

![3-1](https://s2.ixacg.com/2026/03/05/1772695503.avif)

米国リージョンのサーバーを選ぶのがおすすめです。他のリージョンでは一部のAIモデルが利用できません。

#### プロジェクト作成

コンソールに入ったら：

- 「プロジェクトを追加」をクリック
- テンプレートを選択
- **openclaw** を選択

![3-2](https://s2.ixacg.com/2026/03/05/1772696074.avif)

![3-3](https://s2.ixacg.com/2026/03/05/1772696101.avif)

API はまだ入力しなくてOK、そのままデプロイします。

![3-4](https://s2.ixacg.com/2026/03/05/1772696130.avif)

#### ターミナルで初期化

プロジェクトの有効化が完了するまで待ちます：

![3-5](https://s2.ixacg.com/2026/03/05/1772696158.avif)

コマンドを入力：

```bash
openclaw onboard
```

![](https://s2.ixacg.com/2026/03/05/1772696225.avif)

ここでいったん止めて、モデルの準備に行きます

### 四、ステップ2：ChatGPTモデルを購入

ChatGPTをおすすめする理由はシンプルです：

- 月額に対応
- コストがコントロールしやすい
- 初心者向き

20$/月のプランを購入すればOKです。Codexが使えるので、次のモデル設定でCodexを選びます。

### 五、アクセス用ドメインを生成

Zeabur の管理画面に入り：

- Network を開く
- ドメインを生成
- 反映を待つ

その後、Web UI のリンクを見つけて開きます。

### 六、必ずやるべきセキュリティ設定

ここが最も見落とされやすいステップです。

パブリックアクセスを閉じないと：

- 他人にあなたのインターフェースへアクセスされる可能性がある
- モデルの利用枠を消費される

推奨：

- パブリックに公開しているインターフェースを削除する
- もしくは公開アクセス権限をオフにする

必ずやってください。

### まとめ

2ドルのサーバーで、あなたは：

- 自分専用のAIザリガニを持てる
- Feishuボットと連携できる
- AIサービスを継続稼働できる

重要なのはスペックの高さではなく：

**まずは一連の流れを動かすこと。**

本格的に使い始めてからアップグレードしても遅くありません。
